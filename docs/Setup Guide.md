# Python installation

**Installing python packages using requirements.txt** 

```code
pip install -r requirements.txt
```

**Select the virtual envirnoment (powershell)** 

```code
.venv\Scripts\Activate.ps1   
```

# Setup Django Backend

**Create a django project (backend)**

```code
django-admin startproject backend
```

**Run the Development Server (in backend dir)**

```code
python manage.py runserver
```

Visit http://127.0.0.1:8000/ to view backend server.
